# Папка `media/` — музыка и звуки игры

Положи сюда **свои файлы** с именами из таблиц ниже. Игра подхватывает их автоматически
(при старте проверяется, существует ли файл; если нет — звучит встроенный синтезированный звук).

Поддерживаются форматы, которые читает браузер: **.ogg** (рекомендуется), **.mp3**, **.wav**, **.m4a**.

## Звуковые эффекты (`SFX.*`)

| Имя файла | Когда играет |
|---|---|
| `click.ogg` | нажатие кнопки мышью / отпугивание Минитуя |
| `door.ogg` | закрытие/открытие двери |
| `turn.ogg` | поворот офиса (A/D) |
| `tab.ogg` | открытие планшета камер |
| `down.ogg` | отключение питания |
| `buzz.ogg` | помехи, мерцание света, ошибки |
| `step.ogg` | шаги |
| `knock.ogg` | стук в дверь/окно |
| `scare.ogg` | скример |
| `win.ogg` | победа (конец ночи, башня) |
| `alarm.ogg` | сигнал отвлекающей сирены (кнопка Space) *(новый звук)* |

Любое другое расширение тоже подойдёт: достаточно, чтобы имя без расширения совпадало
(например `door.mp3`).

## Фоновая музыка (`BGM`)

| Имя файла | Где играет |
|---|---|
| `menu.ogg` | главное меню и экраны выбора |
| `night.ogg` | ночь (офис, камеры) |
| `tower.ogg` | Башня |

Музыка играет по кругу и автоматически замолкает на экранах победы/поражения/скримера.

## Важно про `file://`

Если открываешь игру просто двойным кликом по `index.html` (протокол `file://`), браузер может
не дать проверить наличие файлов — тогда всегда будет играть синтез. Чтобы свои файлы заработали,
запусти любой мини-сервер из папки игры, например:

```
python3 -m http.server 8000
```

и открой `http://localhost:8000`. На GitHub Pages всё работает без настроек.

Громкость музыки и эффектов меняется прямо в игре: меню → кнопка «🎚 Звук».
