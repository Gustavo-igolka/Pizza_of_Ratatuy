# Pizza of Ratatuy

Игра-пародия на FNAF в браузере (HTML5 canvas). Без сборки и серверов: открой `index.html`
или выложи папку на GitHub Pages. Скрипты подключены обычными `<script>` — работает и с `file://`.

## Структура

```
index.html               — холст и список подключаемых скриптов
css/style.css
js/core/                 — ядро: реестр, состояние, рисование, постобработка (gfx.js), звук, сохранение, ИИ-движок, ночь
media/                   — ТВОИ музыка и звуки (см. media/README.md); чего нет — играет синтез
js/scenes/               — экраны: офис, камеры, меню, выбор, экстра, башня, концовки
js/shared/groups.js      — группы аниматроников (Рок-стары, Toy)
js/shared/walker.js      — готовое поведение «ходок» (Рататуй, Краб, Карась)
js/input.js, js/main.js  — управление и главный цикл (main.js всегда последним)
animatronics/<id>.js     — ПО ОДНОМУ ФАЙЛУ НА КАЖДОГО АНИМАТРОНИКА
animatronics/example-template.js — шаблон (не подключён)
```

Ядро ничего не знает про конкретных аниматроников: оно вызывает их «хуки» (`init`, `update`,
`drawWindow`, `onSiren`, ...). Полный список хуков — в шаблоне и в шапке `js/core/ai.js`.

## Как добавить нового аниматроника (3 шага)

1. Скопировать `animatronics/example-template.js` → `animatronics/<id>.js`, заполнить данные и логику.
2. Добавить в `index.html` строку `<script src="animatronics/<id>.js"></script>` перед маркером
   «НОВЫЕ АНИМАТРОНИКИ ДОБАВЛЯТЬ ВЫШЕ». Порядок строк = порядок в меню.
3. Больше ничего: меню выбора (со страницами), «Экстра» (с прокруткой), Башня, сохранение сложности
   подхватят его сами.

Правила:
- Файл оборачивается в `(()=>{ ... })();` — так локальные имена не конфликтуют с другими файлами.
- `id` уникален (латиница), по нему хранится сложность. Занятый id — ошибка в консоли, аниматроник пропускается.
- Не менять чужие файлы без нужды. Если нужна новая общая возможность — добавить хук в ядро
  (`js/core/ai.js` + место вызова) и описать его в шаблоне.
- Тот же тип поведения у нескольких аниматроников: вынести в `js/shared/<name>.js` как
  `Behaviors.<name>={...}` и подмешивать `registerAnim({...Behaviors.<name>, id:..., ...})`.
- Новая группа: одна строка `registerGroup({id,title,badge})` в `js/shared/groups.js`, у аниматроника `grp:'<id>'`.

## Полезное из ядра

| Что | Зачем |
|---|---|
| `S` | всё состояние: `S.t` (мс ночи), `S.power`, `S.doorL/doorR`, `S.light`, `S.camOpen`, `S.cam`, `S.flash` (фонарик), `S.blockUntil` |
| `kill(o)` | убить игрока этим аниматроником (скример, если `scare:true`) |
| `say(текст)` / `sub(текст,мс)` | подсказка сверху / субтитры внизу |
| `doorClosed('left'/'right')`, `doorHeld(side)`, `windowBusy(o)` | двери и окно |
| `chance(diff)`, `diffLerp(d,лёгкая,сложная)`, `jitter()`, `pickOf(arr)` | сложность и случайность |
| `SFX.knock/door/buzz/step/scare/alarm...` | звуки (сначала твой файл из `media/`, иначе синтез) |
| `bulbLight(x,y,r,seed)` / `neonTitle(...)` | мерцающая лампа / неоновая вывеска (`js/core/gfx.js`) |
| `drawFX(dt)` | постобработка кадра: зерно, виньетка, CRT-развертка |
| `txt, rr, btn, g, mx, my, hits` | рисование и мышь |
| `LOC` | индексы камер: `left:0, right:1, hall:2, prize:3, parts:4` |

## Проверка перед заливкой

Открыть `index.html`, в консоли браузера (F12) не должно быть красных ошибок, в меню «Песочница»
новый аниматроник должен быть в списке.
